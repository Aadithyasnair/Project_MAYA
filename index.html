            ROUND 1 ARCHITECTURE BLUEPRINT
          
          

            How TinyFish Powers Project MAYA
          

          

            Static Python scrapers (`requests`/`BeautifulSoup`) get blocked by Cloudflare Turnstiles and multi-step JS login flows. MAYA orchestrates all 4 TinyFish primitives concurrently via `asyncio.gather`:
          

        


        

          

            
              1. TinyFish Search & Fetch APIs
            
            Thread A // OSINT
          

          

            Performs zero-latency OSINT discovery and pulls clean Markdown telemetry from RDAP/Whois registries, DNS records, and SSL certificate logs to identify registrar abuse contacts.
          

        


        

          

            
              2. TinyFish Agent API (/v1/automation/run-sse)
            
            Thread B // DOM Agent
          

          

            Spawns a stateful headless browser with Live Browser Preview to navigate multi-step fake login flows, inject synthetic canary credentials, and capture hidden POST exfiltration endpoints in structured JSON.
          

        


        

          

            
              3. TinyFish Browser API
            
            Thread B // Takedown
          

          

            Launches a parallel browser session on the hosting provider's abuse portal to auto-populate and submit the formal takedown report with captured DOM evidence.
          

        


        

          

            
              4. TinyFish Monitor API (/v1/monitors)
            
            Thread C // Watchdog
          

          

            Schedules an automated hourly cron watchdog with an LLM diff judge to alert the SOC dashboard the exact moment the registrar suspends the malicious domain (`HTTP 404`).
          

        

      


      
      

        

          

            
              BACKEND ORCHESTRATOR CODEBASE // MAYA_ENGINE.PY
            
            

              FastAPI + TinyFish `asyncio.gather` Pipeline (No API Key Needed for Demo)
            

          

          
        


        
@app.post("/api/v1/neutralize")
async def neutralize_phishing_target(req: NeutralizeRequest):
    """
    Executes the concurrent 3-thread TinyFish counter-deception pipeline.
    Automatically falls back to deterministic simulation in Round 1 demo mode.
    """
    canaries = [generate_canary_token() for _ in range(req.canary_batch_size)]

    async with httpx.AsyncClient(timeout=60.0) as client:
        osint_res, agent_res, monitor_res = await asyncio.gather(
            # Thread A: TinyFish Search & Fetch APIs (RDAP/Whois + SSL Markdown)
            thread_a_fetch_osint(client, req.suspect_url),

            # Thread B: TinyFish Agent (/v1/automation/run-sse) + Browser API
            thread_b_agent_and_browser(client, req.suspect_url, canaries),

            # Thread C: TinyFish Monitor API (/v1/monitors) Hourly LLM Watchdog
            thread_c_monitor_watchdog(client, req.suspect_url),
        )

    return {
        "status": "NEUTRALIZATION_PIPELINE_COMPLETE",
        "target_url": req.suspect_url,
        "canaries_injected": canaries,
        "thread_a_osint": osint_res,
        "thread_b_agent_browser": agent_res,
        "thread_c_monitor": monitor_res,
    }
